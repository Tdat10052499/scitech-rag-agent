Why it exists

Grounded,
not guessed.

Fluent is not the same as correct.

Language models know a lot about LLM research and will answer from memory. That memory has no sources you can check, and it stops at the training cutoff.

ASAP answers only from passages it retrieves, marks each claim with its source n, and says so when the corpus does not hold the answer.

How it works

From 121,860 papers to one cited answer

Every question follows the same path. The agent rewrites it into a standalone search query, retrieves the five strongest passages with meaning-based and keyword search together, and writes an answer from those passages alone. Then it suggests what to ask next.

121,860 papers, processed at scale

The full arXiv snapshot is filtered with PySpark to every paper listed in cs.CL, then cleaned, chunked and embedded into a frozen index. New papers arrive as a scheduled batch.

~460 new papers / week

Hybrid retrieval: dense + BM25

Meaning-based search finds paraphrases. Keyword search finds exact terms like model names. Reciprocal rank fusion merges both rankings and keeps the top five passages.

Answer · sources

Transformers replace recurrence with self-attention, so every token can attend to every other token in one step . Pre-training a bidirectional encoder on masked tokens and then fine-tuning it set new results on many language understanding tasks . Later work showed that a large enough model can pick up new tasks from a few examples in the prompt .

What is chain-of-thought prompting?

Chain-of-thought prompting adds worked, step-by-step reasoning to the examples in a prompt, and this improved large models on arithmetic and commonsense benchmarks 1. Asking the model to "think step by step" without examples also helps 2.
