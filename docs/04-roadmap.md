# Roadmap (8 weeks)

Milestones `Week 1` to `Week 8` are created by the "Bootstrap project" GitHub Action.

| Week | Goal | Deliverable |
|---|---|---|
| 1 | Narrow scope, verify data sources, freeze contracts, dev environment | Updated brief, `03-data-sources.md`, frozen contracts, working `make` commands |
| 2 | Batch pipeline: download, clean, store | Clean dataset and descriptive statistics |
| 3 | Chunking, embeddings, vector store, hybrid search | Retrieval working without an LLM |
| 4 | LLM backend, RAG with citations | Chat MVP |
| 5 | Agent: query rewrite/decomposition, evidence check | Multi-step agent |
| 6 | Follow-up suggestions, complete UI, optional streaming ingestion | Feature-complete demo |
| 7 | Experimental evaluation | Evaluation report with sample sizes and limitations |
| 8 | Polish, final report, demo | Final deliverables |

Rule: every week ends with something runnable on `main`. Reduce scope before sacrificing weeks 7-8 (evaluation).
