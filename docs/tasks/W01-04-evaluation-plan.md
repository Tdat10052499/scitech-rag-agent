# W01-04 Evaluation plan

- Area: evaluation
- Milestone: Week 1
- Depends on: W01-01

## Goal
Decide early how the system will be judged, so evaluation is designed rather than improvised in Week 7.

## Outputs
`evaluation/PLAN.md` covering: research questions, metrics for retrieval, answers and follow-up suggestions, golden-set format and target size, how items are created and checked, baselines to compare (e.g. vector-only vs keyword-only vs hybrid), and threats to validity (sample size, annotator bias, judge-model bias).

## Scope
- May change: `evaluation/`.

## Acceptance criteria
- [ ] Every metric has a definition and a formula or procedure.
- [ ] Golden-set item format is specified with one example.
- [ ] Limitations are stated explicitly.
